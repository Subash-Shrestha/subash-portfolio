# Subash Jayana Shrestha — Portfolio

Personal portfolio site for Subash Jayana Shrestha, a Sydney-based social media strategist and digital marketing specialist.

Single-file static site (`index.html`) — no build step required.

## Deploying with GitHub Pages

1. In this repo, go to **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Set **Branch** to `main` / `(root)`, then save.
4. The site will be published at `https://subash-shrestha.github.io/subash-portfolio/`.
